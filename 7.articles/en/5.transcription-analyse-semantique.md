# Transcription and Semantic Analysis: Giving Meaning to Sound

Isolating a radio chronicle goes beyond simple sound signal detection. On stations like France Inter, transitions are organic, and jingles are sometimes absent or masked by the host's voice. Using a Natural Language Processing (NLP) pipeline allows for high precision in GroovyMorning.

## The Transcription Pipeline

The first step consists of transforming audio into text. Two approaches are prioritized depending on the infrastructure:

1.  **Whisper (OpenAI)**: A robust and versatile model used for background processing.
2.  **Kyutai (Moshi)**: Optimized for low latency on Mac Silicon, allowing for real-time transcription.

The audio stream is cut into chunks and transmitted to the STT (Speech-To-Text) model, which provides the text along with timestamps for each word.

## Semantic Analysis with DeepSeek

Once the text is obtained, identifying the start of a chronicle, such as "The Geopolitics Note," requires more than just a keyword. The **DeepSeek** LLM (Large Language Model) is then requested.

A text window (corresponding to the last 30 seconds) is sent to the model with a specific prompt:
> "You are an expert radio assistant. Analyze this transcription and determine if a chronicle is starting, ending, or if we are in the middle of one. Identify the chronicle name if possible."
Accompanied by a few examples of chronicle start phrases as well as the full list of chronicles scheduled in the broadcast.

The AI is able to understand the context:
*   *Host:* "It's 8:17, time to join Pierre Haski..." -> **START DETECTED**.
*   *Journalist:* "Thank you Pierre, see you tomorrow." -> **END DETECTED**.

## Temporal Recalibration

The processing time required by the AI (inference latency) is taken into account. If a chronicle start is detected at 08:15:10, the text might have been received at 08:15:15.
Using transcription metadata allows for precisely tracing back to the instant the first word was spoken, enabling the Java capture module to start the archive at that exact moment in the buffer's past.

## Conclusion

The combination of Speech-To-Text and the contextual intelligence of LLMs allows for transforming a raw audio stream into a structured database. GroovyMorning thus evolves from a simple capture tool to an intelligent personal assistant.
