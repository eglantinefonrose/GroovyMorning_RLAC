# Model Hub and Datasets: Hugging Face Integration

In a research and development project like **GroovyMorning**, managing model versions and distributing assets (trained models, labeled datasets) is crucial. The project relies on the **Hugging Face** ecosystem to centralize these resources and automate their deployment.

## Asset Centralization

The `4.rd/1.IAChronicleDetector` module regularly produces new AI models (Audio Segmenters, Transcription Detectors). Instead of storing these large files in Git, they are hosted on the **Hugging Face Hub**.

This enables:
- **Strict Versioning**: Each model has its own repository with a commit history.
- **Simplified Distribution**: Production servers (`2.RLAC-IAChronicleSegmenter` module) can dynamically download the latest model version using the `huggingface_hub` library.
- **Documentation (Model Cards)**: Each model is accompanied by a `README.md` file describing its performance, architecture, and training data.

## Pipeline Automation (Push-to-Hub)

One of the strengths of the integration in GroovyMorning is the automation of the process after training. Several scripts facilitate this transition:

1.  **`push_to_hf.py`**: Used in text detection pipelines to upload model weights (e.g., fine-tuned CamemBERT) directly after performance test validation.
2.  **`hf_push_assets.py`**: Manages the upload of datasets and snapshots needed for audio recalibration.
3.  **Direct Trainer Integration**: Training scripts based on the `transformers` library use the `push_to_hub=True` option to automatically synchronize checkpoints.

## Available Models

The project maintains several public and private repositories under the organization or referring user (e.g., `eglantinefonrose/`), including:
- `rlac-audio-segmenter-chroniques`: Native detection via audio signal.
- `rlac-audiotranscript-segmenter-chroniques-hybrid`: Model combining text and temporal metadata.
- `camembert-chronicle-start-detection`: Model specialized in identifying introductory phrases.

This cloud-native infrastructure ensures that the research excellence produced in the R&D phase is immediately exploitable by the production modules of the GroovyMorning pipeline.
