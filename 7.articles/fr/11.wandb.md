# Suivi d'Expériences et Monitoring avec Weights & Biases (WandB)

L'entraînement de modèles d'intelligence artificielle est un processus itératif nécessitant une analyse fine des métriques. Pour assurer la transparence et la reproductibilité des résultats, **GroovyMorning** utilise **Weights & Biases (WandB)** comme plateforme de monitoring centralisée.

## Pourquoi WandB ?

Dans le cadre de la R&D sur la détection de chroniques, nous testons quotidiennement des dizaines de configurations (hyperparamètres, architectures de modèles, tailles de datasets). WandB permet de :

1.  **Visualiser en temps réel** : Suivre l'évolution de la `Loss`, de la `Precision`, du `Recall` et du `F1-Score` pendant l'entraînement.
2.  **Comparer les runs** : Superposer les courbes de différentes expériences pour identifier instantanément quel modèle converge le mieux.
3.  **Debugger les entraînements** : Identifier rapidement les problèmes de sur-apprentissage (overfitting) ou de gradients instables.
4.  **Organiser par Tags** : Utiliser des tags (ex: `wavlm`, `cnn`, `jingle`) pour filtrer les expériences par type d'architecture.

## Intégration Technique

Le monitoring est directement intégré dans les scripts d'entraînement du module `4.rd/1.IAChronicleDetector`.

### Initialisation
Chaque session d'entraînement commence par une initialisation liée au projet global `RLAC` ou `IAChronicleDetection` :
```python
import wandb
wandb.init(
    project="IAChronicleDetection",
    config={
        "learning_rate": 2e-5,
        "architecture": "CamemBERT",
        "dataset": "RadioFrance-V2"
    }
)
```

### Reporting Automatique
Grâce à l'intégration avec les librairies `transformers` et `accelerate`, les métriques sont envoyées automatiquement à chaque étape (`logging_steps`). Le paramètre `report_to="wandb"` dans les `TrainingArguments` suffit à activer cette liaison.

## Tableaux de Bord (Dashboards)

L'interface de WandB sert de "tour de contrôle" pour les ingénieurs IA du projet. Elle permet de générer des rapports de performance qui servent de base à la sélection du modèle final qui sera déployé en production sur Hugging Face. 

Cette rigueur dans le suivi permet de garantir que chaque amélioration apportée au moteur de détection de **GroovyMorning** est scientifiquement validée et documentée.
